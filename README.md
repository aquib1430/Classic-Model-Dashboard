# Classic Model Sales Dashboard

## Overview
The Classic Model Sales Dashboard is an interactive data visualization tool designed to provide insights into sales performance for a classic model store. This dashboard allows users to explore key metrics and trends, facilitating data-driven decision-making.

## Features
- **Sales by Payment Mode:** Visualizes total sales segmented by different payment methods (e.g., COD, UPI, Credit Card) using a bar chart.
- **Sales by Region:** Displays the percentage contribution of each region (East, West, Central, South) to overall sales through a pie chart.
- **Sales by Customer Segment:** Summarizes sales by customer types (Corporate, Consumer, Home Office) with a bar chart.
- **Sales by Product Sub-Category:** Multiple visualizations depict sales performance and profitability across various product categories (Office Supplies, Furniture, Technology).
- **Monthly Sales Trends:** A bar chart showing sales trends month-over-month.
- **Total Sales and Profit:** KPI cards highlighting overall sales ($1.92M) and total profit ($224.08K).
- **Ship Date Analysis:** A timeline displaying product shipment distribution by quarter, aiding in logistics planning.
